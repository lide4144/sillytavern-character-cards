# 角色卡合集

SillyTavern 角色卡与世界观项目合集。

---

## 项目：修女与女忍的双面日常

### 简介

成人喜剧向（欢乐黄油）GM 卡：用户扮演女主角莉莉安——巨乳可爱修女，白天在露米埃尔村的圣露西亚教堂接待村民、募捐修缮（模拟经营养成），夜晚化身月影阁见习女忍「夜百合」，穿暴露女忍装执行潜入任务（败北值满触发战败 H 的潜入剧场）。AI 扮演游戏主持人与全世界。所有登场人物均为成年人。

### 玩法循环

- **白天（经营养成）**：接待村民事件（倾诉/告解/治疗/募捐）→ 民声↑ → 捐款↑ → 花钱修缮 → 修缮进度满 100 教堂升级
- **夜晚（潜入任务）**：忍鸦密信送委托 → 接取后潜入 2~4 个节点 → 失误涨败北值 → 满 100 触发战败 H、任务失败；成功拿报酬
- **联动**：体力昼夜共享；白天的人情/疲惫影响夜里；夜里露馅涨秘密暴露度，满 100 触发村庄误会喜剧事件

### 技术特性

- **MVU Zod 变量系统**（JSONPatch 方言）：六容器（环境/教堂/莉莉安/任务/村民/近期事件），zod schema 为事实源；`[mvu_plot]`/`[mvu_update]` 标记已标注，同轮更新与额外模型解析双模式兼容
- **美化状态栏**：昼/夜双主题 iframe（资金/修缮/民声/体力/羞耻/暴露度进度条，任务中显示败北值红条），卡内正则 + 酒馆助手 html 代码块渲染
- **卡内封装**：世界书 10 条、正则 2 条、酒馆助手脚本 3 个（MVU bundle 运行时从 jsDelivr 远程加载，默认国内镜像优先）

### 文件

- `角色卡_修女与女忍的双面日常_GPT版.png`（推荐封面，GPT Image 2 生成）/ `_二次元版.png` / `_写实版.png`：PNG 卡，拖入酒馆即玩
- `角色卡_修女与女忍的双面日常.json`：JSON 版角色卡（导入后 ST 会抽取世界书为同名文件，卡内已挂接）
- `世界书_修女与女忍的双面日常.json`：世界书独立导出（维护用，勿与卡内嵌同时挂载）
- `部件/`：全部源码（卡文本/世界书条目/脚本/状态栏），`build.mjs` 重新组装，`pack_png.py` 打包 PNG
- `说明.md`：完整制作记录、依赖清单与真机验收报告

### 运行依赖

酒馆助手（宿主必装）；MagVarUpdate bundle 与 mvu_zod.js 运行时从 jsDelivr 远程加载（已封装国内/全球双加载脚本）；Zod schema 已随卡封装。

## 项目：爱

### 简介

修仙世界多角色模拟角色卡。表面是热血漫风格的师门日常与冒险，内里是正常世界的现实主义逻辑——每个人都有自己的利益、创伤和算盘。

### 角色阵容

| 角色 | 名字 | 定位 |
|------|------|------|
| 大师兄 (User) | 李德 | 真心热血笨蛋 / 灵力量大+输出效率高的人形大炮 / 底层并行着对所有人的持续杀意 / 211软件工程穿越者 / 高中「搬椅子事件」是已放下的过去 |
| 师妹 | 沈念 | 重生者 / 天生读心能力+至尊骨 / 第一世被李德杀死 / 重生后以「粉切黑好兄弟」策略接近他 / 她到底想怎样——她自己也不确定 |
| 合欢宗圣女 | 凤轻笙 | 处子妖女 / 理论派天才 / 李德青梅竹马 / 色气全开勾火→等他开口→他不说→生气揉捏→循环 / 喜欢他但害羞不表白 |
| 抱枕女孩 | 小穗 | 被李德从魔物口中救下的唯一幸存者 / 暗恋李德 / 御兽宗天赋者 / 凭依变身（兽耳/尾巴） |
| 师尊 | 云棠 | 年轻时坑蒙拐骗（云中君）/ 现在慵懒护犊子 / 想和李德传承血脉但拧巴说不出口 |
| 师弟 | 周白 | 外门时望见「白衣剑仙」→入门后发现是元气笨蛋 / 正在重新认识大师兄 |

### 世界观要点

- **正常修仙世界**：不是暗黑设定，就是现实——资源有限、人心复杂
- **穿越者前辈**：数百年前击溃邪教后搞时尚，地球服饰全面融入
- **十二天书**：十二位绝世强者 + 时间穿越 + 修正力限制
- **至尊骨**：霸王体质，人形魔兽级肉身
- **御兽宗体系**：独立境界体系（感兽→通兽→御兽→凭依→合兽→万兽）

### 故事框架

五幕关系阶段：磨合期 → 损友成型 → 裂痕觉醒 → 变小危机 → 清算

通过日常与宗门任务交替推进，任务覆盖皇城政治、秘境探索、魔兽生态、魔教侦察等多种类型。

### 技术特性

- **MVU 变量系统**：追踪剧情阶段与小穗觉醒进度
- **EJS 阶段指导**：根据当前阶段自动切换主持目标和互动边界
- **27条世界书条目**：世界观/地理/角色/阶段指导全覆盖
- **格式**：JSON（可导入 SillyTavern）

### 文件结构

```
爱/
├── 爱.json                    # 打包输出（可直接导入）
├── 创作规划.yaml               # 项目完整规划文档
├── schema.ts                  # MVU 变量类型定义
├── tavern-cards-state.json    # 状态文件
├── 开场白/0.txt               # 开场白
├── 世界书/
│   ├── 世界观/世界设定.yaml
│   ├── 扮演准则/扮演准则.yaml
│   ├── 地理/（玄天宗/合欢宗/皇城/边境城市/魔教控制区/古秘境）
│   ├── 角色/（李德/沈念/凤轻笙/小穗/云棠/周白）
│   ├── 阶段指导/阶段指导.yaml
│   └── 变量/（initvar/更新规则/输出格式/变量列表）
├── 正则/
├── 脚本/
└── 开场白/
```

## 使用方式

1. 下载 `爱.json`
2. 在 SillyTavern 中导入角色卡
3. 角色卡内含世界书，自动加载
