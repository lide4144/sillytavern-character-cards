# 修女与女忍的双面日常 · 角色卡说明

成人喜剧向（欢乐黄油）**GM 卡**：`{{user}}` 扮演女主角**莉莉安**——巨乳可爱修女，白天在露米埃尔村的圣露西亚教堂接待村民、募捐修缮（模拟经营养成）；夜晚化身月影阁见习女忍「夜百合」，穿暴露女忍装执行潜入任务（战败即黄油的潜入剧场）。AI 扮演游戏主持人与全世界。

## 生成过程

1. 需求访谈：用户扮演修女本人；变量卡+美化状态栏；欢乐黄油喜剧；直白露骨。
2. 方言查证（关键）：目标运行时为 **MVU Zod（JSONPatch 时代）**。经 MagVarUpdate bundle.js 运行时源码 + STDB B1 手册 + 酒馆助手官方文档交叉确认：
   - `[initvar]` 世界书条目做变量初始化（纯值 JSON，非旧 [value,desc] 二元组）
   - 模型输出 `<UpdateVariable><analysis>…</analysis><JSONPatch>[…]</JSONPatch></UpdateVariable>`，只用 add/replace/remove/move 四种 op
   - `{{format_message_variable::stat_data}}` 宏（酒馆助手提供）把当前变量注入提示词
   - `[mvu_plot]`/`[mvu_update]` 条目名标记在「额外模型解析」模式下做双模型路由（本卡已标注，两种更新模式都兼容）
   - bundle 自动向 AI 消息追加 `<StatusPlaceHolderImpl/>`，卡内正则将其替换为 ```html 状态栏，由酒馆助手渲染成 iframe
3. 变量树设计：六个顶层容器（环境/教堂/莉莉安/任务/村民/近期事件），zod schema 为事实源（prefault + clamp 兜底）。
4. 组装：build.mjs 从部件源码生成角色卡 JSON + 独立世界书 + 正则导出。
5. 静态校验（已通过）：initvar JSON 可解析；mes_example 全部 10 条 patch 路径与 initvar 结构一致、无 replace 不存在路径；顶层容器完整；两条正则可编译；状态栏 payload 格式正确；两个卡内脚本 ESM 语法通过。
6. 导入修正（真机发现）：**ST 导入 JSON 卡时会把内嵌 character_book 抽取成同名世界书文件，且不自动挂接**。因此卡内 `extensions.world` 必须显式指向同名世界书（build.mjs 已修正，已导入的卡也已通过接口补挂）。

## 封面与 PNG 打包

- 封面原图在 `封面/`：A/B 版由本机 Krea2（Moody Krea2 Mix，ComfyUI API 极简工作流：UNET+CLIP(krea2)+VAE+AuraFlow(1.15)+CFGNorm，8 步 er_sde/simple，896×1152）生成；C 版由 GPT Image 2（codex-image，需 /99settings 开 Other providers）生成。
